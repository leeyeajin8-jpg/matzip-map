# 인증맛집 지도 MVP v2

## 이번 버전
- 동작구 → 영등포구/관악구 → 용산구 순으로 데이터 수집 우선순위를 반영했습니다.
- 방송/콘텐츠 출처가 검색으로 확인된 우선 후보 27개를 별도 후보 데이터로 추가했습니다.
- `candidates_priority.json`에서 후보군을 확인할 수 있습니다.
- 네이버·카카오 평점은 제3자 평점으로 대체하지 않습니다. 두 플랫폼 모두 4.0+를 개별 확인한 뒤에만 본 DB로 승격하는 정책입니다.
- 지도/목록, 검색, 카테고리, 복수 인증, Bottom Sheet, 네이버지도 연결 UX는 계속 동작합니다.

## 다음 구현 단계
실제 NAVER Maps API 키를 연결하면 Mock 지도 영역을 실제 지도/마커/클러스터로 교체합니다.
