# 인증맛집 지도

[지도 열기](https://leeyeajin8-jpg.github.io/matzip-map/)

## 수집 기준
- 지역: 서울특별시·인천광역시·경기도.
- 출처: 먹을텐데, 또간집, 최자로드, 백종원(3대천왕·골목식당 등), 수요미식회, 전현무계획, 맛있는 녀석들, 기타 유명맛집, 흑백요리사. 기존 9개 분류를 유지합니다.
- `기타 유명맛집`을 다른 먹방 채널을 추가하는 근거로 사용하지 않습니다. `흑백요리사`도 관련 조건을 임의 해석해 추가하지 않습니다. 이번 자료에서 이 두 분류로 새로 확정한 지점은 없습니다.
- 평점: **네이버 또는 카카오 중 하나라도 4.0 이상**. 미확인 플랫폼은 `null`입니다.
- 네이버 수치는 공개 집계 자료에서 별점 표시가 확인된 항목(`displaysRating=true`)만 사용합니다. 숫자만 저장돼 있고 표시되지 않는 항목은 제외합니다.
- 소개된 실제 지점만 등록합니다. 지점명과 좌표(100m 이내) 또는 정확한 도로/지번·번지를 대조하고, 원문 주소·근거 링크를 보관합니다. 같은 브랜드의 다른 지점에 인증을 복사하지 않습니다.
- 동작구 → 영등포·관악구 → 용산구를 우선하고, 이후 서울 나머지·인천·경기에서 복수 출처와 평점 순으로 선택합니다.
- 같은 인정 출처는 한 번만 계산하며, 서로 다른 인정 출처 2개 이상이면 복수 인증입니다.
- 목표는 300개이며, 조건을 만족하지 못하면 숫자를 임의로 채우지 않습니다.

## 반영 결과
이번 재수집 데이터 **181개**로 기존 자료를 교체했습니다. 임의로 추가했던 먹방 채널은 등록 출처에서 제외했습니다.

- 서울특별시: 151개
- 인천광역시: 10개
- 경기도: 20개

복수 출처 지점: 13개. 원래 9개 출처 필터를 복구했으며, 지역명·주소 검색을 지원합니다.

## 자료와 확인 범위
- [지도를보다](https://seemap.co.kr/): 먹을텐데·또간집·최자로드·전현무계획의 소개 지점과 연결 영상.
- [한류지도](https://hanlyu-map.com/contents): 백종원 3대천왕·골목식당, 수요미식회, 맛있는 녀석들의 소개 지점·주소·좌표·방송 메뉴.
- 회차별 방송 목록 보완: [수요미식회 목록](https://banmal.tistory.com/210), [서울 수요미식회](https://foodfinder.tistory.com/47), [백종원 3대천왕](https://uni-we.tistory.com/57). 정확한 주소가 대조된 지점에 한해 사용합니다.
- [유추카](https://youchuca.popit.kr/): 플랫폼별 평점·주소·좌표·네이버/카카오 지점 링크.
- **공개 집계 자료를 대조한 결과이며 플랫폼 원문 직접 검증이나 실시간 평점은 아닙니다.** 원본 영상 전체를 시청해 검증한 목록도 아닙니다. `source_evidence`와 `rating_evidence`에 각각 근거와 확인 방식을 기록했습니다.
- 평점 측정 날짜를 확인하지 못한 경우 `source_date`는 `null`입니다. `last_checked`는 공개 자료를 조회한 날짜입니다.
- 메뉴는 소개 자료에 명시되거나 해당 지점 리뷰에 실제로 언급된 이름만 최대 3개 저장합니다. 현재 판매 여부·가격은 미확인으로 표시하며 임의 가격을 넣지 않습니다.

## 파일
- `data.json`: 기존 배열 구조·핵심 필드를 유지하고 지역 및 출처 근거를 추가한 등록 데이터.
- `candidates_priority.json`: 기존 우선 후보 및 인정 출처가 있지만 평점 확인이 필요한 후보 121개.
- `data_collection_report.json`: 기준, 수집 개수, 확인 범위, 데이터 해시.
- `index.html`: 지도·목록·저장 3탭 앱. 음식 종류 빠른 필터, 검색 자동완성(가게·지역·메뉴, 최근 검색), 출처·지역·평점·복수 인증 필터, 확대 수준별 마커 묶음, 추천·평점·거리순 정렬, 저장(기기 보관), 상세 화면(평점·리뷰 수, 방송 회차·영상, 길찾기·공유·주소 복사), `?id=` 공유 링크, 뒤로 가기로 시트 닫기, PC 목록+지도 분할 화면.



## 카페·빵집 탐색 (2026-10-03)
- 상단 `맛집 / 카페·빵집` 전환을 추가했습니다. 지도·목록·저장 탭, 상세 바텀 시트, 검색 자동완성과 PC 분할 화면은 현재 디자인을 따릅니다.
- `카페·빵집` 하나의 그룹으로 **76곳**을 등록했습니다. 서울 26곳, 경기 27곳, 인천 23곳입니다. 기존 `data.json`의 맛집 181곳은 그대로 유지합니다.
- 출처별 개수는 네이버 새로오픈 48곳, 블루리본 공식 소개 24곳, 공식 빵지순례·대표 빵집 추천 5곳입니다. 리치몬드 성산본점은 블루리본과 빵지순례에 함께 해당하여 중복 계산됩니다.
- 새로오픈은 2026-10-02 네이버 검색의 `새로 오픈했어요` 영역에서 수집한 실제 Place ID 목록을 이어받았습니다. 45곳은 2026-10-03 조회에서도 `newOpening=true`를 확인했습니다. 실제 개업일이나 스마트플레이스 최초 등록일을 의미하지 않습니다.
- 블루리본은 공식 매장 소개 페이지의 상호·주소를 검색 색인에서 확인한 목록입니다. 공식 소개를 리본 수상과 동일하게 해석하지 않습니다. 확인하지 않은 리본 수·선정 연도는 `null`입니다.
- 빵지순례는 [인천관광공사의 빵지순례](https://itour.incheon.go.kr/thmtour/rcmdtour/detail.do?cotId=ITA21121017510152486), 서울관광재단의 [리치몬드 성산본점](https://korean.visitseoul.net/area/리치몬드-과자점-성산본점/KOP038319) 및 [나폴레옹과자점](https://korean.visitseoul.net/restaurants/나폴레옹/KOP006613) 공식 소개를 기준으로 등록했습니다.
- `새로오픈 / 블루리본 / 빵지순례` 빠른 필터는 복수 선택 시 OR로 동작합니다. 지역·평점·복수 출처 조건은 AND로 적용됩니다. 종류를 전환할 때 각 종류의 필터 선택을 유지합니다.
- 가게명·지역·메뉴·출처 검색, 공백을 제외한 상호 검색, `신상`, `베이커리`, `블루리본 서베이` 검색을 지원합니다. 평점 미확인도 목록에 포함되며 0점으로 표시하지 않습니다.
- 73곳은 네이버 동일 Place ID 또는 정확한 상호·도로명 번지를 대조해 지도 좌표를 확인했습니다. 좌표 미확인 3곳은 지도에 임의 위치를 표시하지 않고 목록 검색·네이버지도 연결로 제공합니다. 해당 주소는 소개 자료 기준임을 상세에 표시합니다.
- 지역 전체의 전수 목록이 아니며 확인된 매장을 담은 목록입니다. 현재 영업 여부·메뉴·가격은 방문 전 매장 원문에서 확인해야 합니다.
- `cafe_bakery.json`: 카페·빵집 데이터, 지점별 선정 근거 링크·확인일, 좌표 대조 근거, 미확인 평점 `null`.
- `cafe_bakery_report.json`: 수집 정책·집계·좌표 확인 범위·파일 해시.
