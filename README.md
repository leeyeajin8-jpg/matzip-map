# 인증맛집 지도

## 데이터 수집 기준 (2026-10-02 변경)
- 서울에 있는 실제 소개 지점만 수집합니다.
- 네이버 또는 카카오 중 한 플랫폼이라도 평점 4.0 이상이면 등록합니다. (`naver >= 4.0 OR kakao >= 4.0`)
- 맛집·먹방 유튜브 소개 지점을 우선하며, 소개 채널과 영상 링크를 함께 기록합니다.
- 동작구 → 영등포구/관악구 → 용산구 → 인접 지역 → 서울 나머지 순으로 수집합니다.
- 조건을 충족하지 못하면 목표 숫자를 맞추기 위해 임의로 평점을 채우지 않습니다.

## 이번 반영
`data.json`에 조건을 충족하는 지점 **300개**를 기록했습니다.

- 동작구: 56개
- 영등포구: 103개
- 관악구: 43개
- 용산구: 98개

## 확인 범위와 자료 출처
- 이번 자료는 [유추카 공개 장소·지역 목록](https://youchuca.popit.kr/)에 표시된 플랫폼 평점, 주소·좌표, 소개 영상 링크를 지점별로 확인해 정리했습니다.
- 네이버/카카오의 플랫폼 원문 직접 확인 및 실시간 평점은 아닙니다. 접근 제한으로 원문 확인이 필요한 상태를 `status`에 표시합니다. 유추카의 자체 평점이나 다른 서비스 평점으로 대체하지 않습니다.
- 다른 플랫폼의 평점을 확인하지 못한 경우 `null`로 보관하며 화면에는 `미확인`으로 표시합니다.
- `rating_evidence`에 플랫폼·평점·리뷰 수·근거 URL·자료 기준일(알 수 없으면 null)·수집일·확인 방식을 기록합니다. 목록과 상세의 평점이 다른 경우 같은 플랫폼의 상세 자료 값을 우선합니다.
- `source_updated_at`은 상세 자료의 기준일이며, 모든 평점이 같은 날짜에 측정됐다는 뜻은 아닙니다. `last_checked`는 공개 자료 수집일입니다.
- `source_videos`는 소개 자료가 연결한 채널·영상 URL입니다. 원본 영상 전체를 시청해 독립적으로 재검증한 목록은 아닙니다.
- `menu`는 소개 자료의 리뷰에 실제로 언급된 이름을 최대 3개 기록합니다. 현재 판매 여부·대표 메뉴 여부·가격을 직접 확인한 값은 아니므로 `menu_status`를 함께 기록하고 가격은 `가격 확인`으로 표시합니다. 언급을 찾지 못한 지점은 빈 배열입니다.
- 소개 문장과 리뷰 원문은 복사하지 않고 지역·업종·소개 채널 등 사실 필드로 설명을 작성했습니다.

## 파일
- `data.json`: 기존 배열 구조와 필드명을 유지한 지도/목록 데이터
- `candidates_priority.json`: 등록된 지점을 제외한 추가 확인 후보 (22개)
- `data_collection_report.json`: 수집 기준·개수·확인 범위와 데이터 해시
- `index.html`: 한 플랫폼 4.0 이상 조건 적용, 미확인 값 처리, 실제 수집 채널 필터, 근거·소개 영상·지점 링크 표시

## 검사

- 카테고리/출처 배열, 소개 영상 링크, 미확인 평점 null, 메뉴 최대 3개
